# استبيان عيادة Just Smile — رؤية للإنتاج الفني

صفحة استبيان تفاعلية لعيادة د. أحمد الميالي لتقويم وتجميل الأسنان (النجف)، منشورة على GitHub Pages:

https://vision-pro.github.io/just_smile/

- الردود تنحفظ بـ Google Sheets عن طريق Apps Script (`apps-script.gs`)، وأسماء الأعمدة تجي من الصفحة نفسها.
- مبنية من قالب «نظام عروض رؤية».
